## 👨‍💻 Обо мне

Backend-разработчик на Python. 3 месяца коммерческого опыта в **DODO BRANDS**: разрабатывал и поддерживал сервисы внутренней аналитической платформы на **FastAPI** и **Django REST Framework**, работал с **PostgreSQL**, **ClickHouse**, **Redis**, **Celery**, **Kafka** и **gRPC**, деплоил в **Docker** и **Kubernetes**, настраивал **CI/CD** в GitLab CI.

- ⚡ Проектирую асинхронные REST API и gRPC-сервисы
- 🗄️ Работаю с PostgreSQL и SQLAlchemy: схемы данных, запросы, оптимизация
- 🧪 Пишу тесты на Pytest и слежу за качеством кода
- 🔭 Настраиваю наблюдаемость: OpenTelemetry, Sentry
- 🎯 Ищу позицию **Junior Python Backend Developer** (также стажировка и проектная работа)
